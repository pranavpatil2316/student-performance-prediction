# Jupyter Notebooks Directory

This folder is designated for exploratory analysis, visualization research, and model development prototyping.

### Prototyping Guides
*   **`01_eda_and_visualization.ipynb`**: Recommended for exploratory data analysis, plotting distributions (e.g. attendance percentage, study hours), checking outlier flags, and plotting correlation heatmaps.
*   **`02_model_development.ipynb`**: Prototyping model comparisons, hyperparameter grid search spaces, and checking classification reports.

To run these notebooks, ensure you install Jupyter:
```bash
pip install jupyter
jupyter notebook
```
Then navigate to this directory and open the notebooks.
